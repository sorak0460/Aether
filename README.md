# Aether Web Remote Server 📱✨

**Aether（イーサー）** は、iPhone（Safari）やAndroid（Chrome）、別PCのブラウザを、PC（Windows / Mac / Linux）の**Apple TV風高機能リモコン**として利用できるようにするWebリモートサーバーです。

専用アプリをインストールすることなく、Wi-Fi経由で超低遅延（1ms台）のマウス操作、スクロール、ドラッグ＆ドロップ、音声入力、ショートカット操作が可能です。

---

## 🚀 別PCでのクイック起動手順

### 1. 必要要件
- **Python 3.9 以上** がインストールされていること

### 2. 起動方法
#### Windowsの場合:
フォルダ内の `start.bat` をダブルクリックするだけです。
（初回のみ自動で必要な依存ライブラリ `websockets`, `pynput`, `qrcode` がインストールされます）

#### Mac / Linuxの場合:
ターミナルで以下を実行します：
```bash
chmod +x start.sh
./start.sh
```

手動でコマンド実行する場合：
```bash
pip install -r requirements.txt
python server.py
```

---

## 📱 iPhone / スマホからの接続方法

1. PC側で `start.bat`（または `python server.py`）を実行すると、ターミナルに**接続用QRコード**とURLが表示されます：
   ```text
   * Web Remote URL : http://192.168.1.15:8080
   ```
2. **iPhoneの標準カメラアプリ** をPC画面のQRコードにかざし、表示された通知（「Safariで開く」）をタップします。
3. PCとiPhoneが同じWi-Fiに接続されていれば、即座にApple TVスタイルのトラックパッド画面が開き、操作可能になります！

### 💡 おすすめ: iPhoneの「ホーム画面に追加」（PWA化）
Safariで開いた後、下部中央の共有ボタン（四角から上矢印のアイコン）をタップし、**「ホーム画面に追加」** を選択してください。
以降はアイコンをタップするだけで、Safariのアドレスバーが消えた**完全全画面のネイティブアプリ感覚**でリモコンを起動できます。

## 🎮 操作方法ガイド

| 操作 | スマホ上でのジェスチャー | PC側での挙動 |
| :--- | :--- | :--- |
| **ポインタ移動** | **指1本でスライド** | カーソルがスムーズに移動（Apple TVデュアルゾーン加速度対応） |
| **左クリック** | **指1本でタップ** | 通常の左クリック（または画面下の `L-Click`） |
| **右クリック** | **2本指で同時にタップ** | コンテキストメニューを開く右クリック（または `R-Click`） |
| **スクロール** | **2本指で上下にスワイプ** | ページやドキュメントを上下にスクロール |
| **慣性スクロール** | **2本指でサッと勢いよく払う** | 勢いに応じて減衰しながら流れるスクロール |
| **ドラッグ＆ドロップ** | **約0.4秒長押し** してから移動 | 端末が振動し、左クリックを保持したままドラッグ。指を離すとドロップ |
| **文字入力** | 下部の `Type` ボタン | スマホで入力した文字列をPCへ直接入力 |
| **音声入力** | 下部中央の `🎙️`（マイク）ボタン | 音声を文字に変換し、PCのアクティブな入力欄へタイピング |
| **設定（⚙️）** | 画面右上の歯車アイコン | マウス速度・**スクロール速度**・加速度カーブを自由に変更（**設定はブラウザに自動保存されます**） |

---

## ⚙️ 設定の自動保存
Webリモコン右上の **⚙️（設定ボタン）** から調整した以下の項目は、端末のブラウザ（`localStorage`）に自動保存され、次回接続時にも自動で復元されます：
- **ポインタ速度（Sensitivity）**: `0.5x` 〜 `3.0x`
- **スクロール速度（Scroll Speed）**: `0.5x` 〜 `3.0x`
- **ダイナミック加速度（Dynamic Acceleration）**: ON / OFF
- **振動フィードバック（Haptic Vibration）**: ON / OFF
